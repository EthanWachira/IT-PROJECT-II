# IT PROJECT II

## Integrated Campus Service Delivery System

A web-based Campus Service Delivery System developed for Strathmore University.

### Technologies

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Git/GitHub

### Project Structure

- `app/` - Application logic, controllers, models and views
- `config/` - System configuration
- `database/` - Database scripts
- `public/` - Public web files
- `routes/` - Application routes
- `storage/` - Application storage

## Project Status

Development in progress.
